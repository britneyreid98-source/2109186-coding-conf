CODING CONF - CIT2011 IA#2

Files:
- HTML/index.html: event landing page
- HTML/login.html: registration form
- HTML/ticket.html: personalized ticket
- css/style.css: page design and responsive rules
- js/validation.js: form validation and browser storage
- js/ticket.js: ticket population and access check
- assets/avatar-placeholder.svg: simple default avatar graphic

HOW TO TEST
1. Extract the ZIP file.
2. Open HTML/index.html in a modern browser.
3. Click Register Now.
4. Enter a name, valid email, GitHub username beginning with @, and a JPEG/PNG image under 500 KB.
5. Submit the form to view the ticket.
6. Try opening HTML/ticket.html directly before registering. It should redirect to index.html.

Note: This is a front-end class project. localStorage is browser storage, not a secure server or database.
